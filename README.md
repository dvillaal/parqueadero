# Sistema de Gestión de Parqueadero

Aplicación full-stack para la gestión y administración de parqueaderos, desarrollada con una arquitectura moderna y escalable. El proyecto implementa un backend basado en Arquitectura Hexagonal utilizando Spring Boot y un frontend interactivo construido con Angular.

## Características
- Registro y gestión de vehículos
- Control de ingreso y salida de vehículos
- Administración de espacios de parqueo
- Consulta de disponibilidad en tiempo real
- Arquitectura desacoplada y mantenible
- API REST para comunicación entre frontend y backend
- Interfaz web intuitiva para administración del sistema

## Tecnologías Utilizadas
### Backend
- Java
- Spring Boot
- Arquitectura Hexagonal
- Maven
- JPA / Hibernate
- Base de datos SQL
### Frontend
- Angular
- TypeScript
- HTML5
- CSS3

## Arquitectura
El backend fue desarrollado siguiendo los principios de Arquitectura Hexagonal (Ports & Adapters), permitiendo:

- Separación clara de responsabilidades
- Bajo acoplamiento entre capas
- Mayor mantenibilidad y escalabilidad
- Facilidad para realizar pruebas y futuras integraciones
